# Nova TV — site vitrine

Site statique (HTML/CSS/JS) hébergé sur Netlify. Chaque modification enregistrée sur la branche `main` est mise en ligne automatiquement.

## Modifier le site depuis GitHub

1. Ouvrez le fichier à modifier, puis cliquez sur l'icône crayon ✏️.
2. Faites votre changement.
3. Cliquez sur **Commit changes**. Le site se met à jour en 1 minute environ.

## Où changer quoi

| Pour changer…                      | Fichier       | Ce qu'il faut chercher          |
|------------------------------------|---------------|---------------------------------|
| Le nom « Nova TV »                 | `index.html`  | `Nova` (logo, titre, pied de page) |
| Les prix des offres                | `index.html`  | `<div class="price">`           |
| Les textes, la FAQ                 | `index.html`  | le texte lui-même               |
| L'e-mail de contact                | `index.html`  | `contact@exemple.com`           |
| Le numéro WhatsApp                 | `script.js`   | `WHATSAPP_NUMBER`               |
| Les couleurs                       | `style.css`   | le bloc `:root` en haut         |
